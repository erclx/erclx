### Eric Le

Applied AI engineer in Gothenburg building LLM applications and developer tools.

### What I build

[**jobtriage**](https://github.com/erclx/jobtriage) is a hosted retrieval and tool-using agent over the Swedish JobTech API. Live demo at [jobtriage.erclx.dev](https://jobtriage.erclx.dev). BYOK across Anthropic, OpenAI, and Gemini with a no-key mock fallback. Hybrid retrieval over a 50-query Swedish golden set with published ablation, plus a React Flow canvas with four views.

[**Stackr**](https://github.com/erclx/stackr) is a VS Code extension for multi-file LLM context preparation. 1,000+ downloads on [Open VSX](https://open-vsx.org/extension/erclx/ai-context-stacker). Also available on the [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=erclx.ai-context-stacker).

[**Caret**](https://github.com/erclx/caret) is a Chrome extension that injects a command-palette prompt picker into Claude, Gemini, and ChatGPT chat inputs. Live on the [Chrome Web Store](https://chromewebstore.google.com/detail/caret/bpmdbibldelkpncegllkeegdpblgehgk).

[**Toolkit**](https://github.com/erclx/toolkit) is an agent-first CLI that installs and syncs governance, skills, and standards across my projects.
