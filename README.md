### Eric Le

AI engineer.

For the past year I have built LLM applications and agents on canon, my public setup for working with AI coding agents. It packages how I work so any project can install it in one command: the rules and skills the agents follow, kept the same across every repository, and a workflow where one session plans, others build in parallel, a separate review checks the work, and I decide what merges. With it I built annex, an EU AI Act agent where I measured whether retrieval still earns its place once the whole law fits in a model's context, and jobtriage, a job-search agent you can try live.

I started out at Volvo Technology, where I spent 18 months on an agent that answered engineers' questions about truck test data in plain language. MSc in Complex Adaptive Systems from Chalmers University of Technology.

Write-ups are at [erclx.dev](https://www.erclx.dev), and I am also on [LinkedIn](https://www.linkedin.com/in/erclx).
